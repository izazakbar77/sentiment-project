🚀 New Project: Sentiment Analysis on Product Reviews using NLP & Machine Learning

I built an end-to-end sentiment classification system that analyzes product reviews and predicts whether they're Positive, Negative, or Neutral — and deployed it as an interactive Streamlit web app.

🔍 What it does:
Takes raw product review text and classifies its sentiment using a full NLP pipeline — from text cleaning to deployment.

🛠️ How I built it:
• Text Preprocessing: tokenization, lowercasing, punctuation removal, and stopword removal
• Feature Engineering: TF-IDF vectorization (unigrams + bigrams)
• Model Training & Comparison: Naive Bayes, Linear SVM, and a Neural Network (MLP) — all trained and benchmarked head-to-head
• Evaluation: Accuracy, Precision, Recall, and F1-score with confusion matrix visualizations
• Deployment: A Streamlit app where you can paste any review and get an instant sentiment prediction with confidence scores

📊 Key takeaway:
Comparing classical ML models (Naive Bayes, SVM) against a simple neural network on the same TF-IDF features was a great way to see the accuracy/complexity tradeoffs in practice — all three landed in the 93-94% accuracy range, showing that well-engineered features often matter more than model complexity for text classification tasks like this.

This project reflects the full ML workflow: data preparation → preprocessing → feature extraction → model training → evaluation → visualization → deployment.

Would love to hear your thoughts, or how you've approached sentiment analysis in your own projects! 👇
